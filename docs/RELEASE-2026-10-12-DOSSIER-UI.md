# پرونده قرارداد — ۱۲ اکتبر ۲۰۲۶

## اصلاحات صفحه

- خلاصه فشرده با مرحله جاری، نقش مسئول و پیشرفت؛ سربرگ، تب‌ها و اقدام بعدی خارج از ناحیه اسکرول سند قرار دارند.
- تب‌های قابل استفاده با صفحه‌کلید و ARIA؛ در موبایل یک ردیف افقی‌اند. تغییر تب انیمیشن ورود پنجره را تکرار نمی‌کند.
- متن سند پیش از هشدارهای تفصیلی دیده می‌شود؛ دریافت متن، چاپ/PDF و ایجاد الحاقیه در نوار خواندن قرار دارند.
- جست‌وجوی متنی با یکسان‌سازی ی/ک، ارقام فارسی/عربی و حروف انگلیسی، برجسته‌سازی و نتیجه قبلی/بعدی. سقف ۳۰۰ نتیجه اعلام می‌شود؛ متن ذخیره‌شده تغییر نمی‌کند.
- اطلاعات ثبت‌نشده و موارد بررسی سند اولیه جدا و جمع‌شونده‌اند. نرخ پیشنهادی، مبلغ توافقی محسوب نمی‌شود؛ مبلغ صفر ثبت‌شده، مقدار معتبر است.
- اقدام پایین صفحه فرم بررسی مرحله را باز می‌کند و نقش لازم را توضیح می‌دهد. اتصال Neo از پرونده حذف شد؛ API و تنظیمات قدیمی اتصال برای سازگاری باقی‌اند.

این تغییر رابط است. پایگاه، migration، مجوزها، کاربران، SSO، ثبت مرکزی، Gateway و شرایط قراردادها تغییر نکردند. قلم، نشان‌ها و tokens رسمی موجود حفظ شدند. README و راهنمای UX هماهنگ‌اند؛ قرارداد Skill/MCP تحت تأثیر نیست.

## پذیرش زنده

سه سناریوی زنده با ورود واقعی SSO موفق شدند: مدیر قرارداد در ۱۴۴۰ و ۳۹۰ و مشاهده‌گر در ۳۹۰ پیکسل. نقش، متن اصلی، جست‌وجو و نتیجه خالی، Enter، تب‌های صفحه‌کلید، ثبات تب هنگام اسکرول، حضور کامل سربرگ/footer و نبود overflow بررسی شدند. دکمه بررسی مرحله و الحاقیه برای مشاهده‌گر غیرفعال بودند. هیچ درخواست نوشتن تجاری یا خطای JavaScript ثبت نشد و قرارداد پیش/پس برابر بود. TLS با CA داخلی معتبر بررسی شد، بدون غیرفعال‌کردن اعتبارسنجی.

تصاویر هر سه سناریو بازبینی شدند. آزمون زنده مشاهده و ناوبری است؛ ثبت الحاقیه/تغییر تجاری روی داده تولید انجام نمی‌دهد. سناریوهای نوشتن و گردش نقش در CI روی پایگاه مستقل موقت هستند. پنل مشتری، Gateway و شارژ کیف پول با این انتشار فعال یا تأیید نمی‌شوند.

این ارزیابی گواهی کامل WCAG یا مطالعه کاربران واقعی نیست. اطلاعات ناقص قراردادها باید در فرآیند بررسی تکمیل شوند؛ این رابط آن‌ها را تأیید یا امضاشده فرض نمی‌کند.
