# رابط پیش‌نمایش پنل مشتری — ۱۱ اکتبر ۲۰۲۶

## قابلیت و منشأ داده

پیش‌نمایش مستقل `/client-preview.html` از پنل واقعی مشتری پیوند دارد. نشان‌های
رسمی فن‌آسا و رایان، قلم محلی وزیرمتن، tokens موجود، RTL و رکوردهای موبایل
استفاده شدند؛ نشان رایان در موبایل نیز قابل مشاهده است.

۳۶۰ رویداد ساختگی سه سرویس نمونه در بازه ثابت استفاده می‌شوند. شاخص تعداد،
نرخ خطا، میانگین، P95، روند ساعتی، پاسخ‌های API، توزیع زمان پاسخ و جدول از
یک مجموعه داده و فیلتر مشترک محاسبه می‌شوند. جست‌وجو ورودی/خروجی، مسیر و
شناسه درخواست را پوشش می‌دهد؛ انتخاب کد پاسخ، فیلتر پاسخ را اعمال می‌کند.
جزئیات، صفحه‌بندی، بازنشانی و نتیجه خالی تعاملی‌اند.

P95 نمونه، nearest-rank دقیق است؛ پنل واقعی همچنان کران بالای P95 از rollup
را نشان می‌دهد. جست‌وجوی نمونه زیررشته و جست‌وجوی واقعی SQL واژه/عبارت است.
پنل واقعی با producer مجاز، مرز تننت و قرارداد API موجود کار می‌کند.

## پذیرش محلی

- سه آزمون محاسبات، سازگاری timeline/status/latency، ترکیب جست‌وجو و فیلتر،
  ارقام فارسی، نتیجه خالی و صدک موفق شدند.
- دو آزمون نهایی مرورگر در ۱۴۴۰ و ۳۹۰: فیلترهای ترکیبی، نمودار یک‌ساعته،
  جزئیات JSON، Enter، Escape، برگشت فوکوس، صفحه‌بندی و بازنشانی موفق شدند.
  API، عملیات نوشتن، overflow یا خطای JavaScript مشاهده نشد؛ تصاویر بازبینی شدند.
- پنج آزمون موجود پنل واقعی مشتری، توافق اقتصادی و ثبت ارائه‌دهنده موفق شدند.
  پایگاه این آزمون‌ها مستقل و موقت بود؛ قراردادهای دمو تغییر نکردند.
- آزمون مرورگر، اجرای گزارش پیش از تکمیل reset بومی فرم و گزینه HTML ناقص
  سرویس را آشکار کرد؛ هر دو اصلاح و در آزمون نهایی دوباره بررسی شدند.

این بررسی تضمین کارایی ترافیک تولید یا گواهی کامل WCAG نیست. backend،
migrationها، وابستگی‌ها، Gateway و حسابداری با این رابط تغییر نمی‌کنند؛
پیش‌نمایش هیچ API، سند مالی، شارژ کیف پول یا مجوز واقعی ایجاد نمی‌کند.
README، راهنمای پنل، UX و پوشش آزمون هماهنگ شدند؛ Skill/MCP وابسته‌ای تغییر نکرد.
