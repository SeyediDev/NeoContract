## اجرای قابل تکرار

```powershell
npm test
npm run test:e2e
```

فرمان دوم هر دو پیکربندی قدیمی و چهار مشتری را اجرا می‌کند. برای اجراهای مستقل
می‌توان از `test:e2e:legacy` و `test:e2e:customers` و پورت اختصاصی
`NEOCONTRACT_E2E_PORT` استفاده کرد. متغیرهای اتصال پایگاه و مجوز مرکزی محیط کاری
در سرور E2E اعمال نمی‌شوند. هر دو مجموعه مرورگر در CI تعریف شده‌اند.

## مرز ادعای تکمیل

- تا ثبت محصول `neocontract` زیر `fanasa.rayan`، چهار UUID مرکزی، عضویت‌ها، مجوز
  ورود و scope/policy سرویس اختصاصی تأیید نشوند، اتصال مرکزی فعال نمی‌شود.
- پنج متن تاریخی پیشنهاد هستند؛ امضای معتبر، شرایط نهایی و entitlement تجاری
  از آن‌ها استنتاج نمی‌شود.
- ثبت مرحله امضا، اتصال به ارائه‌دهنده امضای دیجیتال نیست.
- نرخ‌های نمونه، استعلام روز بازار نیستند؛ نرخ واقعی زودکس باید از استعلام
  اپراتور وارد و منبع آن در مدل نگهداری شود.
- نتیجه محلی آزمون‌ها، جای نتیجه اجرای GitHub Actions یا پذیرش عملیاتی هر
  محیط را نمی‌گیرد. [گزارش پذیرش ۹ اکتبر](RELEASE-2026-10-09-COVERAGE.md) نتیجه
  اجرای این نوبت را ثبت می‌کند.
- [پذیرش پیش‌بررسی مرکزی](RELEASE-2026-10-09-CENTRAL-PREFLIGHT.md) شامل آزمون‌های
  جدید، انتشار، حفظ داده و نتیجه واقعی پیش‌نیازهای تکمیل‌نشده است.
- [پذیرش مقایسه قیمت](RELEASE-2026-10-09-PRICING-IMPACT.md) شامل مقایسه تاریخی،
  پیش‌نویس، نقش مشاهده‌گر و آزمون زنده هر پنج مدل در دسکتاپ/موبایل است.
- [پذیرش ثبت الحاقیه](RELEASE-2026-10-09-AMENDMENTS.md) شامل تلاش مجدد، هویت
  معتبر، شماره‌گذاری تراکنشی، نقش‌ها و بررسی فرم در دسکتاپ/موبایل است.
- [پذیرش پیوست مالی](RELEASE-2026-10-09-FINANCIAL-AMENDMENTS.md) شامل نسخه ثابت
  مدل، مبنای مالی، پیش‌نمایش سرور، دریافت JSON و ثبات مفاد اصلی است.
- گردش بررسی داخلی الحاقیه: ارسال، بررسی حقوقی، بررسی مالی پیوست، رد و لغو؛
  نقش و نسخه مورد انتظار، تلاش مجدد بدون رویداد تکراری و محافظت SQL از متن/پیوست.
  تأیید داخلی، امضای طرفین یا اعمال مبلغ توافق‌شده نیست.
  [گزارش پذیرش بررسی الحاقیه](RELEASE-2026-10-09-AMENDMENT-REVIEW.md)
  نتیجه آزمون‌ها و انتشار این مرحله را ثبت می‌کند.
- [پذیرش خروجی قرارداد و الحاقیه](RELEASE-2026-10-10-DOCUMENT-EXPORT.md)
  شامل CI موفق، انتشار، قلم آفلاین، دریافت پنج بسته واقعی و حفظ داده است؛
  مرز آزمون نمونه موقت رابط الحاقیه و آزمون پایگاه جداگانه در گزارش مشخص شده است.
- [پذیرش اجرای پس از امضا](RELEASE-2026-10-10-CONTRACT-EXECUTION.md)
  شامل CI موفق، PostgreSQL موقت واقعی، انتشار migration ۷، پنج سناریوی SSO/نقش
  و حفظ داده است. مرز نمونه موقت رابط و ثبت واقعی در پایگاه جداگانه مشخص است.
