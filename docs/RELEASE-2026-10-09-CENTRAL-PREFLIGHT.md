  از یک پیاده‌سازی مشترک دریافت توکن، عضویت و تصمیم دسترسی استفاده می‌کنند.

## پذیرش سرور

- دریافت npm در ساخت عادی VPS به timeout رسید؛ نسخه قبلی در دسترس ماند.
  پس از تأیید برابری فایل قفل و تمام بخش‌های manifest به‌جز scripts، تصویر
  با وابستگی‌های تصویر قبلی و آرشیو Git نسخه جدید، بدون شبکه ساخته شد.
  از پرونده‌های خصوصی یا تغییرات خارج Git در ساخت استفاده نشد.
- انتشار با Compose پایه و override خصوصی HTTPS انجام شد. سرویس نهایی
  `running / healthy`، restart صفر و هش فایل‌های اتصال/پیش‌بررسی/فرمان اجرا و
  package در container با blob همان نسخه Git برابر بود.
- نسخه قبلی با برچسب `neocontract-app:before-access-preflight-20261009` حفظ شد.
  backup جدید PostgreSQL با فرمت custom گرفته شد و `pg_restore --list` موفق بود.
- اثرانگشت همه ردیف‌های قرارداد، سند و مدل قیمت‌گذاری قبل و بعد برابر بود:
  ۱۲ قرارداد، ۳۰ سند و ۱۱ مدل، شامل نسخه‌های آرشیوی.
- آزمون زنده SSO ادمین و مشاهده‌گر، چهار تننت، پنج پیشنهاد و مدل مرتبط،
  دسکتاپ/موبایل، منع خواندن/نوشتن خارجی و منع دسترسی به تننت آرشیوی موفق بود.

## نتیجه پیش‌بررسی واقعی

پرونده خصوصی آزمون از چهار subject فعال و از قبل مجازِ دمو در PostgreSQL
با تراکنش فقط خواندنی ساخته و پس از اجرا حذف شد. هیچ subject، رمز یا توکن
در گزارش عمومی ثبت نشد.

| بررسی | نتیجه |
| --- | --- |
| ورود از proxy مورد اعتماد | موفق |
| اعتبارسنجی TLS | موفق |
| کلاینت اختصاصی قراردادها | موفق |
| پرونده چهار کاربر و پوشش چهار مشتری | موفق |
| نگاشت UUID مرکزی مشتریان | ناموفق؛ نگاشت عملیاتی خالی است |
| درخواست توکن با `platform.catalog` | ناموفق؛ HTTP 400 از endpoint توکن |

گزارش `ready:false` و `activationChanged:false` داشت؛ به دلیل شکست این
پیش‌نیازها، بررسی downstream عضویت، admission و کاتالوگ مرکزی اجرا نشد.
در فایل‌های خصوصی سرور گزارش بدون secret نگهداری شد.

`NEOCONTRACT_ACCESS_ENABLED=false` باقی است. ثبت مرکزی محصول زیر
`fanasa.rayan`، UUIDهای قطعی چهار مشتری، scope و policy سرویس، عضویت‌ها و
مجوزهای ورود همچنان باید در مرکز راهبری تکمیل شوند. گذر از پیش‌بررسی نیز
جای آزمون لغو/بازگردانی واقعی دسترسی، نقش‌های SSO و ماندگاری ثبت مرکزی
پس از restart را نمی‌گیرد. اتصال مرکزی فعال یا تکمیل‌شده اعلام نمی‌شود.
